# 前情提要

我從小到大（約莫半個月前）一直都是 Windows 的死忠支持者。

但是 Windows 最近一直讓我感覺拉完了：

1. 編譯速度極慢。
Windows 使用 NTFS（New Technology File System），而 Linux 大多使用 ext4（Fourth Extended Filesystem）。前者在大檔案 I/O 方面很強，但處理大量小檔案時 overhead 很大。
而程式開發屬於後者，編譯、執行時都需要讀寫海量小檔案。每次打比賽用 Linux 的時候，總是讓我很羨慕那個編譯速度。
2. 軟體相容性。
有很多開源的神奇小工具都只能在 Unix 架構上跑，我只能麻煩地尋找 Windows 替代品。
計網概作業的 Makefile 只有給 Unix 版本 :sob:。
3. 閉源，導致系統與硬體驅動之間的相容性問題不斷。
驅動問題真的一直煩我很久了，時不時 Windows Update 給我自動更新，驅動就爛了，還得自己手動從 UX 設計極差的網站裡面翻出不知道能不能用的驅動。
在 2026/9/24 的時候，我點開了 [rekrap2 - No Armor Hardcore - S3 Episode 1 - Lost
](https://www.youtube.com/watch?v=ywehA3HqxZ8) 準備好好享受，但每隔不到 10 秒就掉幀，連 480p 也會掉幀到底是什麼鬼？我的筆電雖然已經三年了，但 i7-13700H 沒理由播不了 4K 影片啊？瞪了一下資源管理器，只要一播影片，3D 運算就蹭蹭往上飆，而 Video encode/decode 穩如泰山，嘗試手動下載 Intel 的驅動程式，結果官網是爛的？好不容易找到了似乎是對的載點，下載下來的東西也是爛的？反正我試了很久不會修，倒是裝個擴充功能強制 h264 就好了。
但這不對啊！！！因此這可以說是壓垮駱駝的最後一根稻草，我一回到家的隔天（9/25）就開始研究**徹底逃離** Windows、擁抱 Linux。

# 擁有 Linux 的方案

按照~~瘋狂程度~~遞增排序。

## WSL 2

WSL（Windows Subsystem for Linux）是在 Windows 裡面跑一個輕量化的 Linux 虛擬機，基本上完全可以取代 Linux 開發需求（解決編譯速度問題，還有計網概作業，我 Lab0 就是用 WSL 2 做掉的），但是日常使用的便利腳本總不可能跑在 WSL 2 內啊！

小科普：WSL 1 是一個「翻譯機」的概念，把 Linux 系統呼叫翻譯成 Windows 能跑的操作，想想就覺得問題很多；而 WSL 2 則是在輕量化虛擬機內跑真正的 Linux Kernel。

另外補述：因為 Windows 閉源、Linux 開源，因此 Windows 易於將 Linux copy-paste 進來，然而反之極難，若是有 Windows only 的軟體需求，建議不要 [Pure Linux](#pure-linux)。

## Dual System

裝 Windows / Linux 雙系統，開機時切換。

理論上是最穩健安全的方案，也很適合作為遷移系統時過渡，但對我來說有種裝尿袋的拖累感，而且我筆電的 SSD 也不大（512 GB），而且我已經下定決心要**徹底逃離**。 

<small> 聽 AI 說 Windows Update 似乎有可能會把開機選系統的選單關掉，讓你直接進 Windows :skull:。 </small>

## Pure Linux

字面意思，等同於重灌，且比重灌更麻煩，因為需要尋找軟體替代品、熟悉新系統，成本極高 :money_with_wings:，但我信~~讀資工系的~~我付得起，且信馬上回本 :money_mouth_face:。

# 遷移計畫

以下只提我的狀況，僅作為參考。

建議先直接關閉 Windows 的快速啟動（在舊版控制台的進階電源設定）、進 BIOS 關閉安全啟動（Secure Boot）。

## 硬體相容性

**TL;DR**

1. 一定要用 Linux Live 測試硬體支援。
2. 測試網路，一定要[測速](https://fast.com/)。
3. 如果打補丁能用，他終究只是補丁。寧願花小幾百塊換個 Kernel 支援的硬體。

---

> Linux Live 記得要選 `Try` 而非 `Install` 否則會造成悲劇。

因為我是筆電（ASUS Vivobook X1605VA），硬體上若是有相容問題會比較麻煩，因此我先燒了一個 **Linux Live** 的開機隨身碟，把筆電上的各個硬體都測了一遍。

- 網卡、藍牙
- 螢幕
- 鍵盤、觸控板
- 鏡頭
- 麥克風、喇叭
- 影印機？

基本上就這些吧。

我測了一輪，我這台電腦上只有 **網卡、藍牙** 有問題：Linux Kernel 抓不到網卡。

先科普一下：在 Linux 上，大部分驅動程式都是直接寫進 Kernel 的，因此正常來說不用額外安裝驅動程式。
（所以說很讚欸，我家兩台印表機他都直接抓到了！以前都要額外安裝廠商給的驅動軟體）

然而我這台筆電上的 MediaTek MT7902 網卡（Wi-Fi + 藍牙）長期缺乏 Linux 官方原生支援（閉源，沒被寫進 Kernel），需要打補丁，我在 Linux Live 上裝了 GitHub 上的其中一個補丁，能 work，就開心收工了！

結果真正裝上 Linux 以後才發現網速超慢，我家 Wi-Fi 隨便跑都有 300 Mbps，愣是只能跑到 20 Mbps，完全不可用。但過一陣子又好了，非常不穩定。

最後我選擇直接 upgrade 到 kernel 7.2，因為從 7.1 開始這張網卡就被寫進 Kernel 了，目前使用起來不再有障礙。

## 備份 Windows

### 個人檔案

我的檔案管理習慣很好，反正是 SSD，我就沒分割磁碟區，直接在 `C:` 開了一個 `我是 D 槽` 資料夾（因為這個資料夾包含非 ascii 的中文字元，害我吃盡苦頭...又不能隨便改，很多設定都習慣很差地寫死了絕對位址 :skull:），所有個人檔案都分類在裡面，因此檔案打包起來非常方便，直接把 `我是 D 槽` 壓成一個壓縮檔就好了。

除了個人檔案，也可以把瀏覽器擴充的設定匯出，像是 tampermonkey 裡的腳本珍藏；安裝在電腦裡的軟體同理。而像是 VS Code 的設定有雲端備份，Google Chrome 也有，就挺方便的 \:)

總之要把所有要**跨系統傳輸**的個人檔案包成常數個 .zip。

### Windows 全機備份

為了能毫無後顧之憂地把原先的 Windows 系統洗掉，我也把整顆 SSD 硬碟備份起來，以便我隨時無痛 rollback。

我是用台灣國網中心開發的免費開源 Clonezilla 再生龍進行備份。

## 遷移 SOP

以下是我自己跟 AI 討論並想出來的遷移 SOP，可供參考？

### 準備工具

- $2$ 個硬碟。容量不同的話較好，比較好分辨。
下面稱此二硬碟為 Boot 跟 Backup。
Boot 用來存放 Linux ISO、Clonezilla Live ISO、要**跨系統傳輸**的個人檔案。這個硬碟**會被格式化**。
Backup 僅用來存放 Windows 全機備份。這個硬碟**不用被格式化**。要傳輸的個人檔案也可以放在這裡。
我原本想用 $1$ 個，且理論上感覺可以，但執行到一半的時候發現**再生龍似乎無法把備份終點設為自己 ISO 的所在位置**？最後臨時修改方案成 $2$ 個，還好沒有影響太多。

- 連續 $n$ 個小時。
最好從一個閒閒無事的假日早上開始以下流程。
~~畢竟資工人失去了電腦等於是失去了全部生產力~~。
主要是在 Linux 剛裝好的時候，會有很多東西需要慢慢裝慢慢調。在正式安裝 Linux 之前，只要關機並把硬碟拔掉，Windows 都還會在。

- 可 USB 共用網路的手機
如果電腦 Wi-Fi 爛了，USB 共用網路可以說是世紀救星。不用是手機的行動數據，手機也能連上 Wi-Fi 以後藉由 USB 共用，而且網速沒什麼損耗。

### SOP

**打包行李，告別 Windows**

首先的首先，把[個人檔案](#個人檔案)整理、打包好，先統一存放在電腦的硬碟裡面就好。

下載 Ventoy。
傳統燒開機碟的軟體（像是 Rufus）一個 USB 裡面只能燒一個 ISO，但 Ventoy 能把 USB 格式化成神奇形式，裡面可以放入多個開機碟，甚至可以存放個人檔案。開機時由 Ventoy 的開機選單選擇要使用哪個 ISO 開機。

使用 Ventoy 把 Boot 格式化。**Boot 裡面的東西會消失**。
分區格式建議選擇 **GPT**，他比較新。

接下來，先把 Linux ISO、Clonezilla Live ISO 丟進 Boot，因為他們的檔案比較大，為了避免碎片化導致後續失敗，先丟他們。

再把個人檔案丟進 Boot（也可以丟進 Backup 啦）。

確保「快速啟動」已經關閉（在舊版控制台的進階電源設定）。

BitLocker 可能會讓再生龍讀不懂你的硬碟而變慢 TAT，反正我沒遇到這個問題，讀者自行注意。

接下來要關閉 Windows 了，*理論上*這會是他最後一次關機，好好跟他道別吧。

按下「關機」的時候可以按住 shift，這樣似乎也能關閉「快速啟動」。

---

**再生龍，備份 Windows**

重新開機，此時要進入 BIOS 或 Boot Menu，所以要按鍵盤的特殊按鍵，建議先查好ww。

如果還沒有關閉「安全啟動（Secure Boot）」的話，可以進 BIOS 把他關掉。

進入 Boot Menu，選擇 Ventoy（可能不會以這個名字顯示，但顯然不會是 Windows）。進入 Ventoy，選擇 Clonezilla。
記得會有一個 `boot in normal mode` 的選項，我忘記在哪一步，反正選他。
Clonezilla 好像也會有一個 `Clonezilla live (Default settings, VGA 800x600)` 選項，就選他。

*以下過程我有點忘記細節了，僅供參考。*

再生龍的選項很多很長，每一步都能 cancel，心理壓力不要太大，慢慢來把所有選項確認好，再生龍很溫馴的。

我忘記具體流程，因此以下是「出現這選項，肯定要選他！」的攻略：

- 選擇 `device-image`（把**硬碟**做成**映像檔**）。
- 選擇 `local_dev`（使用**本機設備**）。
- 選擇 `Beginner`（精靈引導模式）。
- 選擇 `savedisk`（因為要備份的是 Windows 的一整個**硬碟**）。
- 如果遇到「檢查」，通常 skip 就好，因為很耗時，而且沒啥必要。
  只是我記得選項是檢查能否正常 restore，可能是「檢查儲存後的映像檔」？~~我記得 AI 說建議檢查，但我忘記我最後有沒有檢查了。~~

應該會先選擇**備份目的地**，也就是 Backup 硬碟。
我遇到的是他會先小黑框實時掃描顯示目前有偵測到的硬碟，`^C` 結束掃描後會讓你選擇要備份到哪一個硬碟。
我就是在這邊發現不能備份到再生龍所在硬碟，因此才要使用額外的 Backup 硬碟。
應該可以選擇要存在哪一個目錄，還有儲存的名稱。

接下來會選擇**備份來源**，自然是本機 Windows 硬碟。

我有遇到一個「這個目錄不是一個掛載點，是否繼續執行？」的選項，因為備份目的地是一個普通未格式化硬碟裡面的一個普通目錄，而不是一個獨立的硬碟分區（掛載點），所以再生龍會優雅跟你確認。

總之以上所有選單都可以慢慢跟 AI 對拍好再選擇，也可以隨時 Cancel 全部重來。

確定以後再生龍就會開始快樂工作了。

再生龍使用 Block Copy，而不是以檔案為單位複製，且僅會複製已用區塊，所以很快，可以幾乎跑滿硬碟的傳輸上限，再生龍我的英雄。

{% cimg src=Clonezilla_my_hero.png w=85% alt="再生龍我的英雄" %}

最後會有「<font color="yellow">這個映像檔儲存成功: ...</font>」，然後存一些日誌就好了。

但我卡在一個 `Saving PCI info...` 的靜止畫面，結果按一下鍵盤就好了，不確定是他在監聽 `press any key to exit` 還是單純畫面沒 update 到。

總之有黃色成功字樣肯定是好了，要長按電源鍵強制關機也可以。
